# Claude Code Guidelines

## Git Commits

When making git commits, always use the following identity for both author and committer:

```
git commit --author="kartikverma27 <143907877+KartikVerma27@users.noreply.github.com>"
```

Also set the committer environment variables:

```
GIT_COMMITTER_NAME="kartikverma27" GIT_COMMITTER_EMAIL="143907877+KartikVerma27@users.noreply.github.com" git commit --author="kartikverma27 <143907877+KartikVerma27@users.noreply.github.com>"
```
